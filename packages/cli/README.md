# @kairo/cli

Node.js command-line tools for Kairo scene packages.

## Commands

```bash
kairo validate <scene-path>
kairo validate <scene-path> --json
```

`scene-path` may be an exploded scene folder or its `manifest.json` file.

Implemented:

- `validate`

Planned later:

- `create-sample`
- `import-dxf`
- `export-dxf`
- `export-glb`
